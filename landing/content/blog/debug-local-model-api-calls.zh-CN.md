模型 API 调试最常见的问题不是代码本身，而是路径、模型名、认证和协议格式。clovapi 的桌面端把这些信息集中到调用日志里。

## 日志里有什么

每次请求会记录：

- 入站方法和路径
- 上游状态码
- 原始响应片段
- token 用量
- 工具调用数量
- 错误信息

这些信息足够判断是客户端路径错了、上游拒绝了，还是模型响应格式不符合预期。

## 按 API Key 聚合

如果多个客户端共用本地代理，可以按 API Key 聚合查看调用量。clovapi 不保存完整 Key，只保存脱敏标签和指纹，方便调试也避免日志泄漏。

## 推荐排查顺序

1. 先看请求是否进入本地代理。
2. 再看上游状态码和响应片段。
3. 最后检查 api_style、模型 ID 和认证状态。

当你同时接入订阅和自定义上游时，这个顺序通常能最快定位问题。
